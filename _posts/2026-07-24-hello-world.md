This is the first post. Delete it, or edit it in place — everything in
`_posts/` shows up on the home page automatically, newest first.

Filenames follow Jekyll's convention: `YYYY-MM-DD-title.md`. That date is
what controls ordering and the date shown next to the post.

Inline math works, e.g. the eigenvalue problem $K\phi = \omega^2 M \phi$,
and so does display math:

$$
\nabla \cdot \sigma + f = \rho \ddot{u}
$$

Blockquotes pick up the same styling as the about page:

> A quote, callout, or aside goes here.

And code blocks are supported too:

```python
def foo(x):
    return x**2
```
